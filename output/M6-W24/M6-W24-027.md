R | M6-W24-027

ES：¡Ahí está el truco! / Las empresas se basan en esa falta de tiempo de los consumidores / para apoderarse de una cantidad ingente / de datos privados.
ZH：竅門就在這裡！企業正是「基於」消費者缺乏時間這一點，來「霸佔（據為己有）」數量龐大的私密數據。

句型解析：
1. 【感嘆句】¡Ahí está el truco!（竅門就在這裡！）— 固定慣用語，ahí 為地點副詞「在那裡」，estar 表示存在，truco 意為「技巧、竅門、把戲」。
2. 【主要子句】Las empresas se basan en esa falta de tiempo de los consumidores（企業基於消費者的時間不足這一點）— basarse en + 名詞，se 為反身代名詞，en 後接依據的事物。
3. 【目的片語】para apoderarse de una cantidad ingente de datos privados（為了霸佔數量龐大的私密數據）— para + 反身原形動詞表示目的，apoderarse de 為固定搭配。
4. 【名詞片語/數量】una cantidad ingente de datos privados（數量龐大的私密數據）— ingente 意為「龐大的、巨量的」，de datos 說明是什麼的數量。

文法：
1. Basarse en + sustantivo（動詞固定介系詞搭配）— basarse 後接介系詞 en，後接名詞，表示「以…為基礎、基於、依據」。此反身動詞結構說明論點或行動的出發點或依據。
2. Apoderarse de + sustantivo（動詞固定介系詞搭配）— apoderarse 後必須搭配介系詞 de，後接名詞，表示「奪取、控制、據為己有」。此反身動詞帶有強占或不正當獲取的含義。
3. Cantidad ingente（形容詞搭配）— ingente 是較文學性的形容詞，意為「巨大的、龐大的」，修飾 cantidad 時表示極大的數量。在正式語境和書面語中常見，口語中更常用 enorme 或 gran cantidad。

例句：
1. ¡Ahí está el truco! Las plataformas se basan en la distracción de los usuarios para apoderarse de una cantidad ingente de información de comportamiento en línea.（竅門就在這裡！各平台基於用戶的分心來霸佔數量龐大的線上行為資訊。）
2. ¡Ahí está el truco! Las aplicaciones gratuitas se basan en la ignorancia digital de los consumidores para apoderarse de una cantidad ingente de datos de geolocalización privados.（竅門就在這裡！免費應用程式基於消費者的數位無知來霸佔數量龐大的私人地理位置數據。）
