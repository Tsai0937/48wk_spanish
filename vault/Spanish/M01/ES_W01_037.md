Q | ES_W01_037

ES：¿Cuándo anunciarán / que podemos empezar / a hacer cola / para el control de pasaportes, / para que no se acumule / la gente antes?
ZH：他們將於何時宣布我們可以開始排隊進行護照檢查，以免人們提前聚集？

句型解析：
1. 【主要子句】¿Cuándo anunciarán?（他們將於何時宣布？）— 詢問時間，是整個句子的核心問題。
2. 【名詞子句】que podemos empezar（我們可以開始）— 作為動詞 `anunciar` 的直接受詞，說明宣布的內容。
3. 【不定詞補語】a hacer cola（排隊）— 作為動詞 `empezar` 的補語，說明開始的動作。
4. 【介系詞片語】para el control de pasaportes,（進行護照檢查）— 說明排隊的目的。
5. 【目的從句】para que no se acumule la gente antes?（以免人們提前聚集？）— 表示目的，說明為什麼要提前宣布。

文法：
1. Futuro Simple (Futuro Simple) — `anunciarán` 用於表達未來將發生的動作或事件。
2. Presente Simple (Presente Simple) — `podemos` 表示能力或可能性，在此句中是「能夠開始」。
3. Presente de Subjuntivo (Presente de Subjuntivo) — `se acumule` 用於 `para que` 引導的目的從句中，表示目的或意圖。
4. Empezar a + Infinitivo (Empezar a + Infinitivo) — `empezar a hacer cola` 表示「開始做某事」。
5. 反身動詞 (Verbo pronominal) — `acumularse` 在此句中是反身動詞，表示「聚集」。

例句：
1. ¿Cuándo informarán que podemos empezar a recoger el equipaje para la salida del aeropuerto, para que no se aglomere la multitud después?（他們將於何時通知我們可以開始領取行李以離開機場，以免之後人群聚集？）
2. ¿Cuándo avisarán que podemos empezar a pasar por la aduana para la entrada al país, para que no se forme un atasco más tarde?（他們將於何時通知我們可以開始通過海關進入該國，以免之後造成堵塞？）
