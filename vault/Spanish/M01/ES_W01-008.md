D | ES_W01-008

ES：Es importante / que nos aseguremos / de que el niño tenga su asiento reservado, / para que no surjan problemas / cuando nos llamen / para abordar.
ZH：我們必須確保孩子有預訂座位，以免在叫我們登機時出現問題。

句型解析：
1. 【主要子句】Es importante (這很重要) — 表達某事的重要性。
2. 【名詞子句】que nos aseguremos (我們確保) — 作為「Es importante」的主語，說明必須做的事情，動詞使用虛擬式。
3. 【名詞子句】de que el niño tenga su asiento reservado (孩子有預訂座位) — 作為「asegurarse de」的補語，說明確保的內容，動詞使用虛擬式。
4. 【目的從句】para que no surjan problemas (以免出現問題) — 說明確保的目的，動詞使用虛擬式。
5. 【時間從句】cuando nos llamen (當他們叫我們時) — 說明問題可能發生的時間，動詞使用虛擬式。
6. 【不定詞補語】para abordar (為了登機) — 說明叫我們的目的。

文法：
1. Presente de Subjuntivo con "Es importante que" (與 "Es importante que" 連用的現在虛擬式) — 當表達重要性、義務或必要性時，其後接的「que」子句動詞必須使用現在虛擬式。這表示說話者認為某事是必須發生的。
2. Asegurarse de que + Subjuntivo (確保...) — 動詞「asegurarse de」(確保) 後接「que」子句時，如果子句內容是說話者希望或需要發生的，則動詞使用虛擬式。
3. Para que (為了；以便) — 是一個表示目的的連接詞，其後接的子句動詞必須使用虛擬式。它說明主句動作的目的或意圖。
4. Cuando + Subjuntivo (當...的時候) — 當「cuando」引導的子句表示未來尚未發生的動作時，動詞必須使用虛擬式。這表示動作的時間點是不確定的。

例句：
1. Es esencial que confirmemos que el equipaje esté etiquetado, para que no se pierda cuando lo facturen para el vuelo. (我們必須確認行李已貼標籤，以免在他們為航班辦理託運時丟失。)
2. Es crucial que verifiquemos que el billete sea válido, para que no haya inconvenientes cuando pasemos por el control. (我們必須核實機票是否有效，以免在我們通過檢查時出現不便。)
