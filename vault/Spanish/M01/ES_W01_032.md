ES：Revisaremos la pantalla / cada diez minutos / para que no se nos escape / la información de la puerta, / por si hubiera / una modificación.
ZH：我們將每十分鐘檢查一次螢幕，以免錯過登機門資訊，以防有變動。

句型解析：
1. 【主要子句】Revisaremos la pantalla（我們將檢查螢幕）— 表達將要執行的動作，是句子的核心。
2. 【時間片語】cada diez minutos（每十分鐘）— 說明動作發生的頻率。
3. 【目的從句】para que no se nos escape la información de la puerta,（以免錯過登機門資訊）— 表示目的，說明為什麼要檢查螢幕。
4. 【條件從句】por si hubiera una modificación.（以防有變動）— 表示一個假設條件，說明以防萬一的情況。

文法：
1. Futuro Simple (Futuro Simple) — `Revisaremos` 用於表達未來將發生的動作。
2. Para que + Subjuntivo (Para que + Subjuntivo) — `para que no se nos escape` 引導目的從句，表示某個動作的目的或意圖，其後動詞必須使用虛擬式。`escaparse` 在此是反身動詞，表示「錯過」。
3. Imperfecto de Subjuntivo (Imperfecto de Subjuntivo) — `hubiera` 用於 `por si` 引導的條件從句中，表示一個不太可能或假設的條件，通常翻譯為「以防萬一」。
4. 反身動詞 (Verbo pronominal) — `escaparse` 在此句中是反身動詞，表示資訊從我們手中溜走，即「錯過」。

例句：
1. Consultaremos el panel cada cinco minutos para que no se nos pierda la actualización del vuelo, por si hubiera un cambio de última hora.（我們將每五分鐘查看一次面板，以免錯過航班更新，以防有最後一刻的變動。）
2. Escucharemos los anuncios cada cierto tiempo para que no se nos pase la llamada a embarque, por si hubiera un adelanto.（我們將每隔一段時間聽一次廣播，以免錯過登機廣播，以防有提前。）
