Q | ES_W01-022

ES：¿Quién nos explicará el motivo exacto del retraso, / para que podamos tomar una decisión / sobre si debemos esperar o no?
ZH：誰將向我們解釋延誤的確切原因，以便我們能夠決定是否應該等待？

句型解析：
1. 【主要子句】¿Quién nos explicará el motivo exacto del retraso? (誰將向我們解釋延誤的確切原因？) — 詢問未來某動作的執行者。
2. 【目的從句】para que podamos tomar una decisión (以便我們能夠做出決定) — 說明解釋原因的目的，動詞使用虛擬式。
3. 【介系詞片語】sobre si debemos esperar o no (關於我們是否應該等待) — 說明決定的內容。

文法：
1. Futuro Simple (簡單未來式) — 用於表達未來將會發生的動作或狀態。在此句中，「explicará」表示未來將會解釋原因。
2. Para que (為了；以便) — 是一個表示目的的連接詞，其後接的子句動詞必須使用虛擬式。它說明主句動作的目的或意圖。
3. Presente de Subjuntivo (現在虛擬式) — 用於目的從句中，表達不確定或希望發生的結果。在此句中，「podamos」表示希望能夠做出決定。
4. Deber + Infinitivo (應該做某事) — 表示義務、建議或可能性。在此句中，「debemos esperar」表示我們是否應該等待。

例句：
1. ¿Quién nos informará sobre la puerta de embarque, para que podamos llegar a tiempo sin tener que correr? (誰將告知我們登機門，以便我們能夠及時到達而無需奔跑？)
2. ¿Quién nos ayudará con el equipaje, para que podamos pasar el control de seguridad sin dificultad? (誰將幫助我們處理行李，以便我們能夠輕鬆通過安全檢查？)
