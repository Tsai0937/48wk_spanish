A | ES_W01_041

ES：Dígales / a los niños / que se sienten bien / hasta que el letrero de cinturones se apague, / para que no se caigan / si hay turbulencias.
ZH：請您告訴孩子們坐好，直到安全帶標誌熄滅，這樣如果出現亂流，他們就不會跌倒。

句型解析：
1. 【主要子句】Dígales a los niños（請您告訴孩子們）— 命令語氣，是句子的核心指令。
2. 【名詞子句】que se sienten bien（坐好）— 作為動詞 `decir` 的直接受詞，說明告知的內容。
3. 【時間從句】hasta que el letrero de cinturones se apague,（直到安全帶標誌熄滅）— 表示時間點，說明動作持續到何時。
4. 【目的從句】para que no se caigan（這樣他們就不會跌倒）— 表示目的，說明為什麼要坐好。
5. 【條件從句】si hay turbulencias.（如果出現亂流）— 表示一個假設條件，說明在什麼情況下會跌倒。

文法：
1. 命令式 (Imperativo) — `Dígales` 是動詞 `decir` 的第三人稱複數正式命令式，用於給予指令。`decir` 在命令式中是不規則的。
2. Presente de Subjuntivo (Presente de Subjuntivo) — `se sienten`, `se apague`, `se caigan` 用於 `decir que` 結構、`hasta que` 引導的時間從句以及 `para que` 引導的目的從句中，表示指令、時間或目的。`sentarse` 和 `caerse` 是反身動詞，`sentarse` 在虛擬式中是不規則的。
3. Presente Simple (Presente Simple) — `hay` 用於條件從句 `si + presente` 中，表示條件是真實或可能發生的。
4. 反身動詞 (Verbo pronominal) — `sentarse`, `apagarse`, `caerse` 都是反身動詞。

例句：
1. Recuérdeles a los pasajeros que se mantengan sentados hasta que el avión se detenga, para que no se lastimen si hay un frenazo.（請您提醒乘客坐好，直到飛機停下，這樣如果突然煞車，他們就不會受傷。）
2. Avisen a los tripulantes que se preparen bien hasta que el despegue se complete, para que no se sorprendan si hay un movimiento brusco.（請您通知機組人員做好準備，直到起飛完成，這樣如果突然有劇烈晃動，他們就不會感到驚訝。）
