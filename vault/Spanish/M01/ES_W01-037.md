Q | ES_W01-037

ES：¿Cuándo anunciarán /que podemos empezar /a hacer cola /para el control /de pasaportes, /para que no se acumule la gente antes?
ZH：他們將於何時宣布我們可以開始排隊進行護照檢查，以免人們提前聚集？

句型解析：
1. 【主要子句】¿Cuándo anunciarán（他們將於何時宣布）— 詢問未來事件發生的時間。
2. 【名詞子句】que podemos empezar a hacer cola para el control de pasaportes,（我們可以開始排隊進行護照檢查）— 作為動詞 "anunciar" 的直接受詞，說明宣布的內容。
3. 【不定詞補語】a hacer cola（開始排隊）— 作為動詞 "empezar" 的補語，說明開始的動作。
4. 【目的從句】para que no se acumule la gente antes?（以免人們提前聚集？）— 表示宣布的目的。

文法：
1. Futuro Simple（簡單未來式）— 用於表達將來會發生的動作或事件，通常帶有確定性。例如：Llegaremos pronto. (我們很快就會到達。)
2. Presente Simple（簡單現在式）— 用於 "que" 引導的名詞子句中，當主要子句表達確定性或事實時。例如：Sé que vienes. (我知道你來。)
3. Presente de Subjuntivo（現在虛擬式）— 用於 "para que" 引導的目的從句中，表示目的。例如：Estudio para que aprenda. (我學習是為了學習。)
4. Empezar a + infinitivo（開始做某事）— "empezar a" 是固定搭配，表示「開始做某事」。例如：Empezamos a trabajar. (我們開始工作。)

例句：
1. ¿Cuándo informarán que podemos empezar a facturar el equipaje para el vuelo, para que no se aglomere la gente en la entrada?（他們將於何時通知我們可以開始辦理航班行李托運，以免人們在入口處聚集？）
2. ¿Cuándo avisarán que podemos empezar a buscar nuestra puerta de embarque, para que no se pierda la gente en la terminal?（他們將於何時通知我們可以開始尋找我們的登機門，以免人們在航站樓迷路？）
