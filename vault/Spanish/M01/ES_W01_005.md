Q | ES_W01_005

ES：¿Usted sabe / si, / para cuando llegue el avión a destino, / habrán pasado ya las dos horas de retraso / que nos han anunciado?
ZH：您知道嗎，當飛機到達目的地時，我們是否已經度過了他們告知我們的兩個小時延誤？

句型解析：
1. 【主要子句】¿Usted sabe si...?（您知道是否...？）— 詢問對方是否知道某事。
2. 【時間從句】para cuando llegue el avión a destino（當飛機到達目的地時）— 指出未來某個時間點，使用虛擬式。
3. 【主要子句】habrán pasado ya las dos horas de retraso（兩個小時的延誤是否已經過去了）— 詢問在未來某個時間點之前，某事是否已經完成。
4. 【關係從句】que nos han anunciado（他們告知我們的）— 修飾「las dos horas de retraso」，說明延誤的來源。

文法：
1. 虛擬式現在時 (Presente de Subjuntivo) — 用於「cuando」引導的未來時間從句，表示未來可能發生的動作。在此句中，「llegue」表示飛機到達目的地這個未來事件。
2. 將來完成時 (Futuro Compuesto) — 用於表達在未來某個時間點之前將會完成的動作。在此句中，「habrán pasado」表示在飛機到達目的地之前，延誤時間是否已經過去。
3. 過去完成時 (Pretérito Perfecto Compuesto) — 用於表達在過去某個時間點之前已經完成的動作。在此句中，「han anunciado」表示在說話之前，延誤已經被告知。
4. 時間連接詞「para cuando」 (Conjunción temporal para cuando) — 意為「當...的時候；到...的時候」，引導一個時間從句，表示在未來某個時間點之前或同時發生的動作。其後動詞通常使用虛擬式。

例句：
1. ¿Usted sabe si, para cuando lleguemos a la puerta, habrán cerrado ya el embarque?（您知道嗎，當我們到達登機門時，登機是否已經關閉了？）
2. ¿Usted sabe si, para cuando el vuelo despegue, habrán cargado ya todo el equipaje?（您知道嗎，當航班起飛時，是否已經裝載了所有行李？）
