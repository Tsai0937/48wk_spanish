A | ES_W01-041

ES：Dígales /a los niños /que se sienten bien /hasta que el letrero /de cinturones se apague, /para que no se caigan /si hay turbulencias.
ZH：請您告訴孩子們坐好，直到安全帶標誌熄滅，這樣如果出現亂流，他們就不會跌倒。

句型解析：
1. 【主要子句】Dígales a los niños（請您告訴孩子們）— 命令句，指示對方傳達訊息。
2. 【名詞子句】que se sienten bien（坐好）— 作為動詞 "decir" 的直接受詞，說明告知的內容。
3. 【時間從句】hasta que el letrero de cinturones se apague,（直到安全帶標誌熄滅）— 表示動作持續的時間限制。
4. 【目的從句】para que no se caigan（這樣他們就不會跌倒）— 表示告知的目的。
5. 【條件從句】si hay turbulencias.（如果出現亂流。）— 表示跌倒的條件。

文法：
1. Imperativo Formal（正式命令式）— 用於對 "usted/ustedes" 形式的命令。對於不規則動詞 "decir"，其正式命令式為 "diga/digan"。例如：Diga la verdad. (請您說實話。)
2. Presente de Subjuntivo（現在虛擬式）— 用於 "decir que" 結構中，表示命令或要求。也用於 "hasta que" 和 "para que" 引導的從句中，表示時間限制和目的。動詞 "sentarse" 是不規則動詞 (e > ie)。例如：Les digo que vengan. (我告訴他們來。) / Espera hasta que llegue. (等到他來。)
3. Condicional con "si"（帶 "si" 的條件句）— 當主要子句是未來式或表達可能性時，"si" 引導的條件從句使用現在式。例如：Si llueve, no saldremos. (如果下雨，我們就不出門。)
4. Verbo pronominal "caerse"（代名動詞 "caerse"）— 表示「跌倒」。

例句：
1. Dígales a los pasajeros que se queden en sus asientos hasta que el avión se detenga, para que no se lastimen si hay un frenazo.（請您告訴乘客們留在座位上直到飛機停穩，這樣如果突然煞車，他們就不會受傷。）
2. Dígales a los viajeros que se preparen para el aterrizaje hasta que la tripulación lo anuncie, para que no se asusten si hay un movimiento brusco.（請您告訴旅客們準備好降落直到機組人員宣布，這樣如果突然晃動，他們就不會害怕。）
